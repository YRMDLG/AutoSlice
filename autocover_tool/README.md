# AutoCover

AutoCover 是通用的 B 站切片封面工作台，也是统一自动化项目中的本地封面入口。它从成品切片中抽取候选帧，避开片头、片尾和高风险字幕区域，并分别生成 `4:3` 与 `16:9` 封面。

通常不需要单独启动它。在项目根目录执行：

```powershell
python 启动.py
```

启动器会自动启动 AutoSlice 和 AutoCover。需要单独调试时，在本目录执行：

```powershell
python -m autocover.cli serve
```

## 使用流程

1. 载入自动切片或精调后的成品视频目录。
2. 导入投稿标题文档，或直接编辑标题。
3. 从候选帧中选择画面。
4. 在预览区拖动、缩放标题和贴图，调整颜色、描边及画面焦点。
5. 单独导出当前比例，或保存 `4:3` 和 `16:9` 双比例封面。

濑户体不是仓库内的可再分发资源。可以通过 `AUTOCOVER_FONT_PATH` 指向本机合法取得的字体文件。贴图目录通过 `AUTOCOVER_STICKER_DIR` 指定，默认使用项目内的 `stickers` 目录。

## 多视频草稿自动保存

每次成功生成预览后，AutoCover 会把当前视频的标题、文字颜色、描边、文字和贴图布局、背景缩放与焦点、选中帧，以及 `4:3`/`16:9` 的最后成功预览保存成真实文件。草稿默认位于当前封面输出目录：

```text
<封面输出目录>\
└── _AutoCover草稿\
    └── <工作区名称>-<路径摘要>\
        ├── 工作区.json
        └── <视频任务ID>\
            ├── 4x3.jpg
            ├── 4x3-background.jpg
            ├── 16x9.jpg
            ├── 16x9-background.jpg
            └── selected-frame.jpg
```

- 同一工作区中的每个视频各自保存，不会互相覆盖；最后编辑的视频也会被记住。
- 刷新页面、重启浏览器或重启 AutoCover 后，重新扫描同一输入目录和输出目录即可恢复；已有草稿直接读取保存的预览，不会自动重新分析队列中的第一个视频。
- 浏览器本地草稿负责保存刚刚发生的编辑，磁盘草稿负责长期恢复；两者时间不一致时优先采用更新的一份。
- 如果源视频的大小或修改时间发生变化，旧草稿会被忽略，避免把旧画面错误套到新视频上。
- 删除 `_AutoCover草稿` 只会清除继续编辑所需的状态，不会删除已经正式导出的封面；清理前建议先关闭 AutoCover。
- 切换封面输出目录会使用另一套草稿目录。如果希望继续上一次编辑，请保持输入目录和输出目录不变。

## 独立批处理

```powershell
python -m autocover.cli batch "output" --output-dir "covers" --canvas both
```

AutoCover 不调用外部 AI 服务，也不会上传视频、标题或图片。
