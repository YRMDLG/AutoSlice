## 动效

- 原则：状态立即生效，只有视觉做过渡，逻辑与测试不等待动画；拖拽、框选、刮擦、拖动分隔条等直接操作跟手，不加延迟。中途打断时从当前值续接，剩余距离越短用时越短。
- 时长：按下 90ms；悬停进入 120ms、离开 240ms（进快出缓）；开关 180ms；选中与滑块 220ms；视图平移缩放 260ms；AI 面板 300ms；页面交叉淡化 220ms；淡入 180ms；列表依次淡入每项间隔 28ms。
- 缓动：标准曲线 `cubic-bezier(0.2, 0, 0, 1)` 快速响应、柔和落定；AI 面板用 `(0.3, 0, 0, 1)`；滚动用 `(0.25, 0.1, 0.25, 1)`。
- 按钮：背景由 `ButtonFx` 接管绘制，悬停、按下、勾选、键盘焦点四个通道独立过渡；凸起与主按钮的渐变、描边、顶边高光随悬停提亮，按下压暗顶边；键盘聚焦才显示焦点环，鼠标点击不显示。
- 选中：导航与项目的选中底色淡入，2px 钴蓝指示条自中心向两端生长；分段控件凸起滑块在选项间滑动；字幕表格行的悬停、选中、播放三层背景过渡，选中指示条同样自中心生长；时间轴字幕块的底色、描边、主选指示同步过渡。
- 视图：定位字幕、适合全部、滚轮平移缩放时时间轴视图平滑移动，缩放按对数插值；播放时在 150ms 一次的位置上报之间按速率外推，误差指数衰减，播放头连续滑动；点击跳转时播放头滑向新位置。
- 显隐：状态提示、定位输出、查看待确认、导航角标出现时淡入，消失时留快照淡出；AI 面板宽度平滑展开收起，内容在到位后淡入以免逐帧重排；切换页面时整块主区域交叉淡化；项目列表刷新依次淡入；载入字幕时表格与时间轴淡入；切换 AI 建议时详情淡入。吸附线吸住时快速浮现、松开后缓慢退去；框选框松手后留一瞬残影再淡出；波形生成后淡入。
- 其他：分隔条悬停浮现细线、拖动时变强调色；音量滑块悬停时把手放大、按下时浮现光晕；输入框与下拉框边框随悬停、焦点变色；滚轮平滑滚动，触控板保持原生；菜单、下拉与提示使用 Qt 自带淡入。
- 降级：离屏平台、Windows「显示动画」关闭或 `AUTOSLICE_REDUCED_MOTION=1` 时全部瞬时完成。

## 方向与层级

- 「碳黑·钴蓝」：暖中性碳黑底衬冷钴蓝，冷暖对比让唯一的强调色更亮、更干净；底色彩度极低，不给视频画面染色。导航、项目、工作区、视频表面依次使用不同明度，面板之间以 4px 深色缝隙（`canvas`）分隔，不再用浅色分割条。
- 质感靠光而不是颜色：凸起控件使用自上而下的微渐变与 1px 顶边高光（`highlight`），按下时顶边变暗形成内凹；输入框使用比面板更深的 `well` 并压暗顶边，表现凹陷。
- 强调色只落在焦点上：主操作（实心钴蓝渐变配白字）、播放头、时间轴选中块、吸附线、开关开启态、焦点框、菜单高亮。导航与项目的选中态使用中性抬升加 2px 钴蓝边线，图标与文字保持白色。
- 时间码使用等宽数字字体（Cascadia Mono / Consolas）；控件高度 32px，圆角统一为控件 6px、容器 8px、徽标 4px。右键菜单与提示框使用 `overlay` 浮层色。
- 视频表面是字幕页视觉中心；默认纵向比例偏向字幕工作台：视频约 42–45%、时间轴约 8–10%、字幕列表约 38–42%，并保留 splitter 自由拖动。AI 侧栏默认收起为 48px 入口，展开目标 320–380px，可用 splitter 调整。
- 不使用大面积厚边框、层层 GroupBox、后台 Dashboard 式卡片或多种亮色状态。占位内容须明确标记为预览，避免被当成实际扫描、字幕或 AI 结果。

## 尺寸与排版

- 一级导航 72px；顶部应用栏 56px。项目列默认 252px、最窄 188px，跟随横向 splitter 可拖动；工作区优先占宽。
- AI 收起 48px，展开初始 324px、最窄 280px；右侧与中央工作区由 splitter 分开。视频、时间轴、字幕列表由纵向 splitter 分开。
- 间距阶梯 4 / 8 / 12 / 16 / 24 / 32px，常用圆角 8px。基础按钮高 36px，字幕行高 48px，项目条目按状态为 62px 或 78px；避免在单个 widget 中自行定义同类尺寸。
- 字体优先随程序分发的源流黑体 `Resource Han Rounded CN`（思源黑体圆角版，SIL OFL 1.1，位于 `src/autoslice/resources/fonts`，由 `qt_preview/fonts.py` 启动时加载，仅打包常规与中等两档），缺失时依次回退 `Noto Sans SC`、`Microsoft YaHei UI`、`Segoe UI`；时间码与字幕时间列使用 `Cascadia Mono` / `Consolas`。字体栈集中在 `theme.py` 的 `UI_FAMILIES` / `MONO_FAMILIES`。基础文字 12px，区标题 13px，页面标题 17px，主占位标题 20px；只打包 400/500 两档：正文 400，标题、主次按钮、品牌字与 AI 新增文字统一 500，不写 600/700，避免触发合成粗体。
- 项目标题最多两行，第二行按宽度省略；普通项目约 62px，有重要状态时约 78px。“素材已识别”不占状态行；字幕已保存、缺少字幕等有意义状态可显示。列表禁止横向滚动，hover 和选中有轻量背景。状态 badge 使用淡强调底或中性抬起层。

## Desktop-07.5 字幕工作台层级

- 采纳使用最强的实心钴蓝；跳过和重新检查使用中性按钮。重新检查位于 AI 标题右上，提示“再次调用 AI 并消耗额度”。
- 当前选中字幕行使用暗蓝底；当前播放字幕使用更弱的中性灰底。时间轴 selected cue 使用蓝色描边与轻填充，current playback cue 使用中性灰描边与底色，hover 仅轻微提亮。项目选中使用弱背景和细边缘线，不再整块亮蓝。
- AI 展开后依次为标题及处理进度、cue 序号、原文与词级差异、简短原因、置信度、采纳/跳过。多条建议的导航列表置于操作下方并限制高度；所有正文随栏宽换行，侧栏不出现横向滚动。
- playhead 竖线顶部有可抓取的小三角把手，hover 显示水平拖动光标；拖动时在时间轴上方显示毫秒级时间提示，松手后隐藏。Desktop-07.6 将命中区扩展到整条竖线，字幕块覆盖处的编辑优先级见下节。

## Desktop-07.6 产品化收口

- 背景采用 `canvas` 应用底、`nav/rail` 导航与工具栏、`panel` 字幕和时间轴工作面、`player` 视频表面四级明度；交界使用 1px 分割线。主操作使用 `accent` 实心色，选中行与项目使用暗蓝淡底及细边缘，播放中的字幕使用更弱中性灰，hover 只轻微提亮。
- `Palette` 维护按钮、项目、字幕选中、播放高亮、AI 差异的颜色；`Metrics` 维护字号、间距、控件高度、图标与 playhead 命中宽度。局部自绘只从令牌取值，不在业务代码重复定义色值。基础文字 12px，字幕正文及建议差异 14px，序号/时间/置信度 11–12px；字幕行高 46px，取消表格竖线，以对齐和淡横线组织阅读。
- 一级导航保留 72px 窄栏，字幕、封面、设置统一使用 20px 线性 SVG 图标和细活动指示。
- 图标在 20px 网格上绘制：1.5 线宽、圆角端点与拐角、内容留 2–3px 边距；播放、暂停、更多用实心，其余为线性。按屏幕缩放比渲染到物理像素，不做二次缩放。导航与主操作用 20px，工具按钮用 16px（`tool_icon`），可勾选按钮开启时图标随文字变蓝。设置为齿轮、压制为「导出」箭头，避免与亮度、播放混淆；不再用 `‹ › … ↻` 等字符冒充图标。项目列表仍是最多两行标题的紧凑行，选中为轻背景及边缘线，不生成项目缩略图。
- 顶栏以当前项目为主信息，工作栏显示视频文件；单视频显示文件名，多视频才显示选择控件。空闲时顶栏状态区域收起，只有 AI 检查、字幕压制、成功或失败反馈出现。保存字幕与压制字幕放在同一组工作流操作中，保存为实心主操作，压制为带边框次操作；保存和压制完成反馈短暂显示并自动收起。保持系统 Windows 标题栏。
- 播放、暂停和音量沿用同一线性图标，保存、压制、定位输出与导航也使用同一套线性图标和尺寸。播放按钮、倍速选择及音量控件按统一高度和间距排列。AI 展开时当前建议是视觉中心：原文、加大字号的词级差异、弱化的原因与小型置信度、采纳主操作与跳过次操作。无建议时隐藏空动作与明细，只留简短提示及重新检查入口；“跳过”保持清楚的次按钮。
- 窗口低于 850px 逻辑高度时，纵向 splitter 初始比例适当让出视频高度给字幕列表，保留视频约 200px 最小高度；跨越该高度时更新一次比例，仍允许用户继续拖动 splitter。
- 时间轴可见竖线保持 2px，逻辑 hit target 宽 14px 且贯穿整个时间轴高度；字幕块覆盖处优先处理块移动和边缘调整。空白轨道按下即 seek，继续移动即 scrub；保持约 150ms 预览节流、松手精确定位和毫秒级浮层。
- 动效统一由 `qt_preview/motion.py` 提供，规则见「动效」一节；splitter 拖动本身保持跟手。项目缩略图、封面视觉及发布图标另阶段处理。

## 控件状态与响应

- 按钮必须有 normal、hover、pressed、disabled；主操作使用唯一强调色，次操作使用中性层。导航项有 hover 和 checked；输入框与文本区有 focus 与 disabled。
- 滚动条是窄轨道与低对比度把手；splitter 平时是与应用底同色的深色缝隙，hover 仅稍微变亮，按住拖动时才使用中等强调色，避免默认亮蓝横线贯穿工作区。
- Qt 布局使用逻辑像素和布局管理器，不按屏幕分辨率硬编码绝对坐标。预览最小窗口为 960×640；2560×1440 以较大留白和内容主次关系优先，1920×1080 与 1366×768 下应保留导航、项目、主视频、薄时间轴、字幕列表和 AI 入口。
- 当前预览不保存 splitter 尺寸、页面或窗口几何；Desktop-04.6 随正式壳迁移实现会话恢复与多显示器边界处理。高 DPI 由 Qt 处理基础缩放，实际不同系统缩放/显示器切换仍需实机验收。

## 页面关系与后续接入

一级入口固定为字幕、封面、设置。字幕和封面共用同一项目列容器；设置页不显示项目列。顶部仅容纳项目上下文、后台状态与少量全局动作。封面页当前只留画布工作面，不实现画布。Desktop-04.6 在此壳上接入现有项目服务与 SRT 操作，Desktop-05 接播放器，Desktop-06 接时间轴，Desktop-07 接 AI。

## Desktop-08.5 字幕工作台最终视觉基线

- 字幕列表以正文为第一阅读层级：表头缩小并弱化，序号与时间列使用较弱文字和较窄宽度，正文保持 14px 与 48px 行高；不显示网格竖线，仅用极淡横线、对齐和留白组织列表。选中行使用暗蓝底与左侧细指示，播放所在行使用更弱中性灰底，hover 不冒充选中。
- 项目列表继续使用紧凑双行标题，只展示待确认、AI 检查中、字幕已保存、封面草稿等高价值状态。选中项目使用弱背景和细边缘线，不生成缩略图。
- 1366×768 默认 AI 收起，字幕列表仍保留可读行数；2560×1440 默认比例由 token 控制，视频约 42–45%、时间轴约 8–10%、字幕列表约 38–42%，用户可继续拖动纵向 splitter。
- 空闲顶栏不显示“准备就绪”。后台状态使用“项目 · 压制中 · 62%”“项目 · AI 检查中”等短文本；完成反馈提供“定位输出”并在短暂提示后收起。保存、压制和定位输出在同一组操作中保持高度、圆角、图标和 disabled 状态一致。
- 无项目、无字幕、视频加载失败、AI 未配置/无建议、压制失败均使用短提示或页面内空状态，不使用巨大错误卡片堆叠，也不改变既有业务处理语义。

- 当前字幕循环用短状态反馈，菜单项带勾选；边界试听不常驻工具栏。
- 非连续选择时“合并所选字幕”保持禁用，并提供轻量解释。
