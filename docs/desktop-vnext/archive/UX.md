# Desktop vNext 交互契约

## Desktop-08.7 剪辑式字幕交互

产品核心原则：**文字：点哪里就改哪里。时间：用 playhead + 波形调整。批量错误：用框选/多选处理。AI：负责带用户去问题位置。最终效果：直接在视频画面里看。**

字幕工作台把 `playhead`、`active cue` 和 `selected cue set` 分开管理。底部字幕列表单击会设置 active、选中对应行、滚动到该行并定位到 cue 开始后暂停；时间轴字幕块单击只设置 active/selected，不 seek、不移动 playhead、不自动居中。Ctrl 点击增减，Shift 点击从 anchor 连续选择。空白按下后移动超过约 5px 才进入矩形框选，使用明显交叠规则实时预览，松手确定；普通空白单击只定位并暂停。Esc 清除编辑或多选。字幕列表和时间轴使用同一 selection model；多选时 active 仍只有一条，Q/W 只改 active，Delete 一次删除整个 selected set 并只生成一条 undo command。

时间轴不设选择/剪刀/手形模式。播放头三角和整根竖线可拖动 scrub，字幕块覆盖处优先块移动或改边界。磁吸由统一 Snap Engine 处理，默认开启，按屏幕约 8px 阈值吸附字幕 start/end，吸住时显示贯穿轨道的青绿色参考线；Alt 临时旁路且不改变开关，带脱离迟滞。Q/W 要求定位线位于 active cue 内部；Ctrl+B 在安全边界内拆分，文字编辑时按 caret 分割，没有 caret 时右侧文本保持待补全，不猜断句。

时间轴默认可显示轻量单轨波形；波形、字幕块和 playhead 共享同一缩放/平移坐标。Ctrl+滚轮以鼠标时间为中心缩放，普通滚轮平移，“适合全部”恢复全视频范围。波形和预览派生物只写应用私有 cache。

字幕正文采用原位编辑语义：第一次点击正文进入编辑并按实际字符位置放置 caret；同一 active cue 再次点击只移动 caret，不重复 seek。文字编辑时 Space、Delete、Q、W 和普通字符都由编辑器处理；非编辑态 Space 播放，F8 在窗口任意焦点播放。底层命令登记为 `play_pause`、`trim_start_to_playhead`、`trim_end_to_playhead`、`split_at_playhead`、`delete_selected_cues`、`undo`、`redo`、`toggle_snapping`、`toggle_waveform` 和 `fit_timeline`，快捷键设置页留到后续。

实时预览使用现有 ASS/libass 样式规则生成私有临时 ASS，文本修改后约 180ms debounce 更新播放器字幕，预览开关可临时关闭。质量提示只在明显超长、超过两行或显示时间过短时显示为轻量提示，不阻止保存。AI 建议点击后同时设置 active/selected、滚动列表和时间轴、seek 到 cue start 并暂停；采纳/跳过后自动定位下一条 pending 建议。

## 整体外壳与项目

- 不设首页/Dashboard。首次打开进入字幕校对，以后恢复上次页面；一级入口仅有“字幕校对”“封面制作”“设置”。
- 字幕页和封面页各自显示同一投稿根目录的项目列表；每个标题文件夹是一个项目，刷新即重新扫描，不要求手动添加，也不长期占据两列导航。
- 切页保留各页状态，包括字幕当前项目、播放/处理位置、待确认队列，以及封面当前项目和草稿。字幕检查、压制等后台任务继续运行；顶部只显示简洁状态。完成后可从封面页一键返回对应项目的待确认字幕。

## 字幕工作台

- 主界面由项目列表、可直接看/听原视频的播放器、常驻且不过高的轻量字幕时间轴、字幕列表和 AI 建议侧栏组成；日常核对不依赖外部播放器或剪映。
- 点击底部字幕行会定位视频并保持暂停；时间轴字幕块点击只选中，不定位、不自动播放。单击字幕文字直接编辑；`Delete` 删除当前字幕，`Ctrl+Z` / `Ctrl+Y` 撤销/重做。
- 时间轴的亮青色块只表示唯一选中字幕；较弱的蓝灰色表示播放指针所在字幕，两者可以不同；hover 只轻微提亮。细竖线始终表示视频当前时间，不表示字幕选择。点击时间轴空白位置会定位并暂停，且不改变字幕选择。
- Desktop-07.6 起，单击时间轴空白位置立即定位；在空白处按住移动直接 scrub。playhead 的可见竖线保持纤细，整条时间轴高度有约 14px 宽的逻辑命中区，顶部三角、竖线中段和下段均可抓取，hover 为水平拖动光标。字幕块覆盖处仍由字幕块优先处理：中部移动字幕，左右边缘调整边界。scrub 显示毫秒级时间提示，途中 seek 约每 150ms 至多一次，松手精确定位；选中的字幕不随 scrub 改变，播放位置仍以 mpv `time-pos` 为准。
- 非文字编辑态：`Space` 或 `Ctrl+Space` 播放/暂停；`Delete` 删除选中字幕；`Ctrl+Z` / `Ctrl+Y` 撤销/重做字幕文档；字幕列表获得焦点时 `↑` / `↓` 切换选中行并定位。文字编辑态：普通字符、`Space`、`Delete` 和 `Shift+Enter` 由编辑框处理（`Shift+Enter` 换行）；`Enter` 提交并退出编辑；`Ctrl+Space` 仍可播放/暂停；`Ctrl+Z` / `Ctrl+Y` 先提交当前文字，再撤销/重做字幕文档。点击别处失焦也提交编辑并恢复单份正文显示。切回非编辑态后窗口快捷键恢复。
- 时间轴字幕块可整体拖动，左右边缘可调整起止时间；拖动/resize 只改字幕时间，不抢 playhead。列表与时间轴双向同步。波形是可选辅助视图，不默认大面积常驻，并跟随当前缩放窗口。
- 底部滚动条、普通滚轮和鼠标侧键只移动时间轴视野；侧键按住持续平移，松开或窗口失活立即停止。行内编辑单击进入，同一句内可自由定位 caret、拖选局部文字并 Delete；点击编辑器外提交退出。F1/F2/F3/F4 保持现有试听语义。
- AI 检查由用户主动启动并在后台运行，切到封面页不打断。结果呈现为待确认队列，优先展示原文与建议文字差异，再给简短原因和辅助置信度；不呈现为长篇分析报告。
- Desktop-07：页面加载、刷新、切项目与恢复会话只读取私有建议会话，不触发模型。首次“AI 检查”可复用有效缓存；已有会话上的“重新检查（再次调用 AI）”先明确提示消耗额度。运行中顶部显示项目名与“AI 检查中”，批次阶段没有可靠进度时不显示百分比；可切页，完成后在字幕导航显示待确认数量，并提供返回对应项目的入口。取消在批次边界生效；失败后保留字幕草稿，可主动重试。
- 建议区默认收起；有待确认建议时展开。点击建议选中唯一对应字幕，定位到起点并暂停，不自动播放；当前播放字幕与指针仍各自独立。建议只显示文本差异、简短理由和已有置信度。采纳写入同一字幕文档并进入撤销、dirty、草稿和正式保存；跳过不改正文、移出待确认队列。两者处理后前进到下一条待确认建议。已删除或手改的字幕保留旧建议供对照，但禁用采纳并提示冲突；用户可跳过或主动重查。列表筛选为“全部 / 待确认”，不推断不可靠的逐条“已修改”状态。
- Desktop-07.5 的 AI 栏从顶部连续显示“AI 建议 x/N → cue 编号 → 原字幕/建议差异 → 简短原因 → 置信度 → 采纳/跳过”；操作下方是左对齐、紧凑的待处理问题列表，每行显示 cue 编号、原文/建议摘要和待确认状态。文字按栏宽换行，不横向滚动。“重新检查”收为标题右侧的次要动作，仍提示再次调用 AI。待确认数保留在字幕导航和列表筛选，AI 栏显示处理进度；应用顶栏不重复显示同一个数字。
- 每条 AI 建议只有“采纳”“跳过”两个处理动作；跳过即不采用并结束该建议。需要手改时直接编辑字幕文字，不另设“拒绝”或“自己修改”按钮。建议处理状态与字幕编辑的撤销语义一致；可提供轻量的“全部 / 待确认 / 已修改”等筛选。
- 字符质检、低频样式参数不长期占据主界面。字幕样式放在设置或压制高级选项；日常压制使用默认样式。
- 编辑自动保存可恢复草稿；键入不直接覆盖原始 SRT。用户明确执行“保存校对字幕”后才写正式校对结果。字幕压制是后台任务，不锁住整个软件。

### Desktop-08.5 视觉与状态收口

- 工作栏把“保存字幕”和“压制字幕”作为一组连续动作：保存是实心主按钮，压制是带边框次按钮，二者保持相同高度、圆角、图标和禁用反馈。有未保存修改或没有正式校对 SRT 时，压制仍先确认保存，保存成功才启动后台任务。
- 顶栏空闲时保持安静，不显示“准备就绪”。AI 检查、字幕压制、失败和完成才出现短状态；压制中显示项目名和可靠百分比，完成后显示“✓ 压制完成”和“定位输出”，短暂反馈后状态自动收起。跨项目任务始终带来源项目名，同项目运行中压制按钮进入禁用的“压制中…”状态。
- 字幕列表正文是主要阅读层级，序号和时间只作辅助；选中、当前播放和 hover 保持可区分。项目标题最多两行，状态仅显示待确认、AI 检查中、字幕已保存、封面草稿等高价值信息。
- AI 侧栏默认收起；有待确认建议时按既有规则展开。采纳为主按钮，跳过为明确的次按钮；无建议时只保留简短空状态和重新检查入口，不留下大块空白。
- 未选择项目、项目无字幕、视频加载失败、AI 未配置/无建议和压制失败均使用页面内短提示；不新增业务弹窗或改变 Desktop-08 的保存、压制、缓存和后台任务语义。

### Desktop-08 字幕压制

- 工作栏在“保存字幕”旁提供次级“压制字幕”。日常压制使用旧默认样式和默认导出参数；设置页只显示默认样式摘要，本阶段没有高级样式编辑器。
- 有未正式保存的编辑，或尚无 `*_校对.srt` 时，点击压制先询问“保存并压制”；保存成功后才启动。取消或保存失败均不压制，草稿照常保留。压制期间继续编辑只影响下一次保存，不会改变本次已复制的校对 SRT 快照。
- 顶栏用“项目名 · 正在压制”及旧 FFmpeg wrapper 在可靠视频时长下给出的真实百分比显示状态。NVENC 回退后不再显示可能回退的百分比。同一项目运行中禁用重复启动；切页面或项目不会停止任务。完成显示项目名、输出文件名及“定位输出”；失败显示操作提示，详细原因可从状态提示和应用日志查看。不同项目的任务消息始终带来源项目名。
- 关闭窗口且仍在压制时提供“继续后台（最小化）”“停止压制并退出”“取消”；当前后台工作线程依附桌面进程，真正退出后不能续跑。停止后清理临时工作文件，再处理未保存字幕的既有离开规则。

## 封面工作台

- 与字幕页共用项目扫描结果。定位为有设计辅助能力的快速封面编辑器：保留输入投稿标题、可编辑文字、表情包、16:9 / 4:3 双比例同步与解除同步后的独立微调、快速导出。
- 默认设计清楚、醒目、几秒可读；通常使用一个主视觉中心、1–2 个主体、1–3 个文字块、1–2 个强调色、0–1 个表情包或装饰。避免为制造“AI 感”堆特效。
- 用户主动请求“智能推荐”时，一次给 3–4 个肉眼明显不同且总体克制的方向，例如大字冲击、人物主视觉、梗图对话、截图故事；仅换颜色不算不同方向。AI 负责理解标题、提炼封面文案，并提出构图、强调词和配色角色；本地渲染器确定坐标、字号、描边与自适应布局。结果必须成为可编辑对象，不能以不可编辑 PNG 作为工作结果。
- “再大胆一点”“按这个思路再来几个”作为以后可扩展的主动操作。参考封面由用户放入；分析人物位置、标题层级、强调色、背景处理等结构，再生成自己的可编辑布局，并缓存分析结果。
- 不用 AI 时封面功能完整可用。标题到思路优先 Luna；高级参考分析、当前封面诊断才考虑 Terra；所有 AI 调用均由用户主动触发，相同输入结果应缓存。
- 单击文字直接编辑；仅按 `Enter` 换行，改变框宽不自动改行。拖动文本框边角按视觉比例缩放文字；字号数值仅作内部或高级参数。保留粗体，支持局部文字换色。
- 颜色入口包括一排 B 站常用高饱和色、用户保存颜色，以及完整选色器、HEX 和吸管；不限制为少量固定色。
- 文字和图片尽量在画布直接拖动、缩放、旋转，并支持基础层级前后移动。文字可调字体、颜色、描边、简单阴影、局部强调色；表情包可拖动、缩放、旋转、翻转。
- 背景可平移、缩放、裁剪、调亮/暗化、模糊，可增加饱和度和对比度。抠主体/人物是用户主动触发的工具，不默认运行。
- 支持 `Ctrl+Z` / `Ctrl+Y`、复制、删除、对齐辅助线、中心与边缘吸附、安全区提示。16:9 / 4:3 默认可同步，解除同步后各自微调；一个比例上可显示另一比例的安全区。
- 右侧属性栏仅显示当前选中对象相关的属性。不建设完整 Photoshop：暂不做钢笔、贝塞尔、复杂蒙版、通道、曲线、色阶、HSL、Liquify、大量混合模式或笔刷系统。

### Desktop-08.7.1 字幕高频操作

`Ctrl+B` 拆分会把一个源 cue 记录为连续 segment 组，正式保存写入校对 SRT 与状态 JSON；重开后按稳定 segment ID 恢复文本、时间和顺序。无 caret 时右侧文本留空，避免猜测断句。右键菜单和“…”提供边界试听、当前字幕循环和连续相邻字幕合并。边界试听在起点或终点附近各取约 0.5 秒并自动停止；循环带约 0.2 秒余量，切换 active cue 后跟随。合并仅接受连续选择，中文直接拼接，英文单词边界补空格，作为一次撤销命令。

波形由后台任务从真实视频音轨下混为单轨幅度包络，首次显示“生成波形中…”，完成后与字幕块和 playhead 共用同一时间坐标。缓存位于 `%LOCALAPPDATA%\AutoSlice\cache\waveforms`，视频路径、大小和修改时间变化会使缓存失效。

### AutoCover-01 实际交互

封面页沿用字幕页当前项目和视频。左侧显示投稿项目、视频、草稿状态和两个底图入口：导入本地图，或填写视频秒数后异步取帧；取帧期间不阻塞字幕页和主窗口。中央只展示 16:9 画布预览，右侧编辑标题、横向/纵向位置和字号，并明确提示沿用现有描边与阴影。

标题、位置、字号、选中帧和底图在编辑过程中自动保存到本机应用数据；切回字幕页再回来或重启后，使用同一项目+视频恢复。导出是显式动作，当前只提供 JPG，输出写入项目目录并使用 `AutoCover-视频名.jpg` 及安全递增命名。普通编辑不触发 AI；“封面文案/构图建议”只作为手动入口占位，后续接入时必须缓存结果并保持可编辑。
