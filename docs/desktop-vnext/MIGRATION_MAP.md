# Desktop-01 — 旧 AutoSlice 能力迁移地图

审计日期：2026-09-28。范围为本仓库现行生产实现 `src/autoslice/`、`src/autoslice_cover/` 及其 Web 页面；根目录同名 Python 文件是兼容入口。以下是静态代码审计，未启动服务、调用模型或处理真实媒体。这里的“可独立使用”指是否能脱离旧 Web 页面和自动分析/自动切片流程调用，不代表脱离 Python、FFmpeg 或其他运行依赖。

## 范围与边界

- 投稿目录由 `AUTOSLICE_SUBMISSION_DIR`、本机配置或仓库内 `submissions` 默认值决定，页面也可提交 `root_dir`；不是源码中固定路径。本次确认的本机投稿目录存在，且与本机配置一致。[配置](../../src/autoslice/runtime_config.py#L84-L113) · [路由](../../src/autoslice/web/app.py#L2204-L2234)
- AutoCover 在本仓库的生产代码为 `src/autoslice_cover/`；`autocover_tool/` 保留旧启动和数据兼容用途。[项目结构](../../README.md)
- 下表的建议针对能力与契约，不包含旧 HTML/CSS/JavaScript 页面的迁入。

## 迁移时需显式保留的事实

1. 投稿扫描是请求驱动的全量递归扫描，当前页面没有目录监听；前端排序不是扫描函数的排序结果。
2. 校对文件与源 SRT 分离；保存的 `*_校对状态.json` 依赖源和产物指纹。AI 建议缓存是另一份 `*_字幕校对建议.json`，采纳/忽略/撤销状态主要在浏览器内存中。
3. 字幕页只有指定秒数的带字幕静帧预览；已有短片媒体 Range 服务绑定自动分析任务清单，不能直接拿来播放任意投稿文件。
4. AutoCover 的双比例同步发生在浏览器编辑状态，后端按比例单独渲染；磁盘草稿负责恢复编辑数据、选中帧与预览。
5. AutoCover 可选读取自动切片的精调 manifest；无 manifest 时仍可扫描视频、取帧、制作封面。自动分析不是字幕校对或封面制作的必需步骤。
