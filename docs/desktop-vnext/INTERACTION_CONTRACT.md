# Desktop vNext 交互契约

> 作用：记录已经验证或冻结的可操作行为。后续重构、UI Cleanup 或模型替换时，不得因为“代码更漂亮”而无意改变这些行为。

## 1. 总原则

- 当前动作优先于系统解释。
- 用户手动操作优先于后台自动化。
- 选中、播放、hover、编辑和任务状态必须分离。
- 页面切换不能让后台旧任务写回新项目。
- 自动保存只能保护工作，不得等同于正式输出。
- 任何昂贵操作都应显式、后台、可取消。
- 实机体验可以推翻自动化测试结论。

## 2. 项目列表

项目来自 `F:\Videos\投稿` 扫描。

要求：
- 刷新项目列表是明确按钮。
- 切项目立即响应。
- 当前项目与后台任务绑定。
- 切换项目时旧 generation 的回调直接丢弃。
- 不因为封面分析、波形、AI 或全片扫描阻塞项目切换。

## 3. 字幕列表和编辑

- 单击字幕正文进入编辑，不双击。
- 点击同一 cue 时只移动 caret，不重复 seek。
- 行内编辑保持当前行稳定。
- 中文 IME 需要正常工作。
- Shift+Enter 插入换行。
- 点击编辑框外提交。
- 编辑态 Delete 只处理文本选择，不删除字幕行。
- 非编辑态 Delete 删除当前字幕选择。
- 文本编辑退出后恢复窗口级快捷键。

## 4. 字幕时间轴

空白区域：
- 单击：seek 到该位置并 pause。
- 拖动超过阈值：框选字幕。
- playhead 独立可拖动，并连续 scrub。

字幕块：
- 单击时间轴字幕块：只改变字幕选择，不 seek。
- 拖中部：移动 cue。
- 拖左右边缘：调整 start/end。
- 移动和 resize 不改变 playhead。
- Ctrl 点击：toggle。
- Shift 点击：range。
- snap 默认开；Alt 临时绕过。

底部字幕行：
- 单击：选择并 seek 到 cue start。## 5. 字幕快捷键

非编辑态：
- Space：播放/暂停。
- 左/右：既有跳转语义。
- 上/下：既有切行语义。
- Q：active cue start → playhead。
- W：active cue end → playhead。
- Ctrl+B：split。
- F1：当前字幕 + 上下文试听。
- F2：start 前 0.5 秒到 start，停止。
- F3：end 到 end 后 0.5 秒，停止。
- F4：精确 cue 播放一次；重复按重新播放一次，不做 toggle。

Q/W 只有 playhead 位于 active cue 内时才执行。

## 6. 字幕 AI

- AI 检查由用户主动启动。
- 页面加载、刷新、切项目不自动调用 AI。
- AI 可以后台运行，用户可切到封面页。
- 建议项点击后导航到对应 cue 并暂停。
- 每条只有“采纳 / 跳过”。
- 采纳进入同一个 SubtitleDocument、Undo/Redo、dirty、草稿与正式保存链路。
- 跳过不修改正文，只从待处理队列移除。
- AI 侧栏应紧凑，不抢正文和视频空间。

## 7. 字幕保存和压制

- 自动保存：只写可恢复草稿。
- 显式保存：写正式校对字幕。
- 原始 SRT 不被草稿覆盖。
- 压制使用既有稳定 workflow。
- 压制在后台执行。
- NVENC 可用时优先，失败按既有回退。
- 输出文件同名冲突需要安全避让。
- 退出时对后台压制按既有语义处理，不静默丢任务状态。

## 8. AutoCover 进入方式

进入封面页：
- 共享当前项目和视频。
- 读取字幕页当前 playhead 快照。
- 不反向控制播放器。
- 不读取字幕预览图层。
- 从原始视频文件取封面帧。

首次页面：
- 当前帧先出现。
- 附近帧渐进补齐。
- 不等待全片分析。
- 自动基础封面可以出现，但不能阻塞用户操作。## 9. AutoCover 选帧

默认重点是“当前时刻附近的最佳瞬间”，不是全片全球最优帧。

附近帧条：
- 围绕当前 playhead。
- 缩略图后台渐进生成。
- 点击即切换底图。
- 切换项目时旧缩略图任务失效。

锁定当前帧：
- 锁定后基础文案变化不换帧。
- AI 候选不换帧。
- 后台推荐不换帧。
- 草稿恢复后仍保持锁定。

“寻找更多画面”：
- 用户显式触发。
- 扩大时间范围。
- 不作为页面默认任务。

## 10. AutoCover 文字对象

A/B 是独立 TextObject。

A：
- 最小上下文；
- 可不存在；
- 默认弱于 B。

B：
- 核心信息；
- 主视觉；
- 不应因为“主视觉”就覆盖人物脸。

交互：
- 点击文字即可选中。
- 鼠标从按下点开始拖，不跳到左上角。
- 手势可继续到对象外。
- 拖动时只做暂态轻量更新。
- 释放时提交文档、历史、草稿和预览。
- 单右下角缩放行为优先沿用旧版已验证手感。
- 中心吸附阈值和辅助线优先沿用旧版行为。
- 点击空白取消文字选择或进入背景上下文。## 11. AutoCover 文字排版

- 手动换行优先。
- 自动换行使用真实字体度量。
- 自动结果不产生明显 1–2 字孤短尾行。
- A/B 不合并为一个字符串后再排版。
- A/B 之间保留清楚间距。
- 默认总文字高度不能占据大半画面。
- 没有足够空间时依次考虑：调整块宽、缩小字号、减少 A、只保留 B。
- 不用大块文字硬盖主体。

WYSIWYG：
- Canvas / Preview / Export 共享同一字体和样式定义。
- 选中框和辅助线只是编辑叠加层，不改变正式文字外观。
- 缺失样式使用 AutoCover 正式默认或风格继承，不使用 Qt 偶然默认。

## 12. AutoCover 背景

BackgroundObject 独立于文字。

支持：
- cover / contain；
- 平移；
- 缩放；
- 每个比例独立取景覆盖；
- 导入底图。

用户一旦手调背景，后台建议不能偷偷重置。

## 13. 双比例

顶部明确：
- 4:3；
- 16:9。

共享：
- 文案内容；
- 对象身份；
- 素材来源。

可独立：
- x/y；
- 对象尺寸；
- 背景 pan/scale；
- fit/crop；
- 必要的显示状态。切换比例：
- 不丢另一比例状态。
- 不覆盖另一比例 profile。
- 返回后恢复原微调。

导出：
- 当前比例导出信息必须明确。
- 支持分别导出。
- 可提供双比例导出按钮，但不能让用户不知道导出了什么。

## 14. 素材和其他对象

ImageObject / StickerObject：
- 点击选中；
- 拖动；
- 缩放；
- 旋转；
- 复制；
- 删除；
- 前移/后移。

ShapeObject 第一版：
- 圆圈；
- 箭头；
- 矩形强调框。

不做复杂图层面板。
z-index 可以存在于底层，但 UI 只提供轻量层级操作。

素材入口：
- 按需展开；
- 最近/常用/当前主播优先；
- 不常驻占画布空间。

## 15. AutoCover Undo/Redo

至少覆盖：
- 文字移动/缩放/删除/样式；
- 背景平移/缩放；
- 图片/贴图移动/缩放/旋转/删除；
- 候选应用。

拖动过程不把每个 mouseMove 写成历史。
释放/明确提交才产生一条可撤销动作。

## 16. AutoCover AI

AI 入口默认关闭。

候选：
- 稳妥；
- 换个构图；
- 大胆一点。

规则：
- 用户主动点击才运行。
- 候选是结构化可编辑 CoverDocument/LayoutSuggestion。
- AI 推荐一个，但用户自己应用。
- 可以返回“没有明显更优方案”。
- 不修改锁定帧。
- 不覆盖用户手调对象。
- 不用分数替用户决定审美。## 17. AutoCover UI Cleanup 契约

当前 Beta 功能已铺开，但最终 UI 需要收口。

最终方向：
- 画布始终是中心。
- 顶部只保留比例、Undo/Redo、导出等主动作。
- 右侧一次只显示当前对象所需属性。
- A/B 优先直接点击画布对象选择。
- “样式”再展开颜色/描边/阴影。
- “更多”再展开旋转/层级/精确数值。
- 素材独立抽屉。
- AI 独立抽屉或浮层。
- 底部附近帧保持轻量。

禁止重新回到“右侧所有参数全部摊开”的管理后台式界面。

## 18. 验收标准

技术检查：
- 单测；
- Qt/QTest；
- ruff；
- compileall；
- git diff --check。

产品验收：
- 真实 Windows；
- 真实投稿项目；
- 真实字体；
- 真实窗口尺寸；
- 连续做多个项目；
- 实际导出检查。

规则：
**技术检查通过只能说明契约没有明显回归，不能直接宣称视觉/产品体验通过。**
