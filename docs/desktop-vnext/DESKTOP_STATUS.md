## 状态结论

Desktop vNext 已经从“基础壳和局部能力”进入“功能基本铺开、集中实机收口”的阶段。字幕模块的交互语义已经冻结；AutoCover Beta 的核心编辑模型、双比例画布、素材、选帧、保存和导出链路已经接通。下一阶段的重点是 Beta UI Cleanup 和统一实机验收，而不是继续把所有参数堆到主界面。

## 字幕模块：语义冻结

字幕页的以下语义作为 Desktop vNext 的稳定契约：

- 项目按投稿根目录扫描；项目文件夹是项目事实来源，草稿和缓存只补充编辑状态。
- 播放器、字幕列表、轻量时间轴和 AI 建议区共享当前项目上下文，但各自的选中、播放和 hover 状态不混用。
- 单击字幕文字进入编辑；编辑框内的字符、空格、Delete 和换行由编辑框处理，提交或失焦后恢复单份正文显示。
- 非编辑态的播放/暂停、删除、撤销/重做和列表上下移动保持既有快捷键语义。
- 时间轴空白处点击定位并暂停；按住移动进行 scrub；字幕块中部优先移动，左右边缘调整起止时间；scrub 不改变字幕选中态。
- 唯一选中字幕使用青绿色主状态，播放所在字幕使用较弱的蓝灰状态，hover 只轻微提亮，playhead 是独立的细竖线。
- AI 检查由用户主动启动，在后台运行，可切换到封面页；页面加载、刷新、切换项目和恢复会话不自动调用 AI。
- 建议只提供“采纳”和“跳过”；采纳写入同一字幕文档并进入撤销、dirty、草稿和正式保存，跳过不改正文并移出待确认队列。
- 自动保存只写可恢复草稿，不覆盖原始 SRT；显式保存校对字幕后才写正式 `*_校对.srt`。
- 字幕压制沿用旧工作流和默认样式，作为后台任务运行，不把压制状态机塞进主窗口的页面控件。

本轮文档整理不修改字幕语义，也不借整理之名重新设计字幕交互。

## AutoCover Beta：已经铺开的能力

当前桌面 AutoCover 已接入下列能力，具体实现以 `src/autoslice/desktop/` 和 `src/autoslice_cover/` 的真实 owner 为准：

- `CoverDocument` 作为持久化主模型，`CoverDraft` 负责旧版本草稿兼容和迁移。
- A/B 两个独立 `TextObject`，可以分别选中、编辑、拖动、缩放、隐藏、删除和保存。
- `BackgroundObject` 支持从原始视频取帧、导入底图、平移、缩放、`cover/contain` 取景和裁切相关状态。
- 4:3 与 16:9 共用一套对象，但分别保存文字位置、尺寸、背景缩放、平移和取景状态，并可分别导出。
- `ImageObject`、`StickerObject` 和 `ShapeObject` 已进入模型和画布边界；图片/旧版贴图支持导入、移动、缩放、旋转、复制、删除、前移和后移，强调形状覆盖圆圈、箭头和矩形。
- 统一的文档快照 Undo/Redo 已接入；拖动过程只更新轻量暂态，释放鼠标后才提交历史、自动保存和预览任务。
- 从字幕页进入封面页时继承当前 playhead；封面底图从原始视频取帧，不把字幕预览层烧进封面。
- 附近帧后台渐进生成；支持锁定当前帧，以及用户主动扩大采样范围的“寻找更多画面”。锁定状态写入 `SourceRef`，草稿恢复后仍然有效。
- 基础文案采用确定性提取和压缩，保留 A（上下文）/B（主视觉信息）结构；当前字幕和附近字幕只参与语义上下文，不直接绘制到封面。
- 默认布局复用安全区域、边缘能量、anchor 和 slot 思路；文字 fit 使用实际字体 bbox 搜索字号和断行，避免 1–2 字孤短尾行。
- 字体文件入口支持 TTF、TTC、OTF；未指定时继续使用已经验证的默认字体路径。
- 旧版素材库接入按需扫描，支持最近、常用和主播优先的素材排序；风格记忆与导出历史提供连续生产所需的轻量回退信息。
- AI Beta 当前是显式候选契约和本地 mock 三候选，可返回可编辑的布局文档；真实 relay 没有作为默认依赖接入。
- 项目草稿、双比例预览、选帧、导出和轻量历史已经落盘；项目切换、取帧、附近帧、预览和另一比例预览使用 generation token 丢弃迟到回调。

## 当前未完成与已知问题

### 必须先做：Beta UI Cleanup

当前 UI 仍有明显的“功能堆叠感”，不能把现有界面当成最终设计目标：

- 右侧上下文面板同时暴露文案、字号、样式、素材、强调框、层级、AI 和低频数字参数，信息架构没有按当前动作收口。
- 画布被顶部、右侧和底部控件挤压，4:3 场景尤其明显；画布没有稳定占据工作区中心。
- 素材、AI、颜色/描边/阴影、旋转/层级和精确数值应改为抽屉、展开区或“更多”入口，右侧一次只展示当前对象真正需要的内容。
- A/B 应优先通过画布对象直接选择；不应在右侧永久摆放一整套工程参数。

### 需要统一实机验收

- 默认字体在目标 Windows 机器上的加载、fallback、字宽和实际视觉层级。
- 默认构图在真实截图、人物主体、界面文字和字幕区域下的安全性。
- 基础文案的质量、A/B 关系、孤短尾行回退和不同标题类型的稳定性。
- 4:3 / 16:9 独立微调后的保存、恢复、预览和分别导出。
- 附近帧渐进生成、锁帧和“找更多画面”在切换项目、刷新和重启后的行为。
- 图片、贴图和强调形状的命中、拖动、旋转、层级与 Undo/Redo。
- 多视频连续生产、导出历史、失败恢复和源文件不变性。

### 尚未完成的产品能力

- AutoCover Beta UI Cleanup 和统一视觉基线尚未完成。
- 真实 AI relay、稳定的模型调用额度提示和线上候选质量仍属于后续阶段；本地 mock 不代表真实 AI 质量。
- LayoutEngine 的长期抽取、更多风格记忆和跨项目质量评估尚未完成。
- 本文不把任何未完成项转化为代码修改要求；路线见 [ROADMAP.md](ROADMAP.md)。
