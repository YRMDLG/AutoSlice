## 验证清单（按顺序做，前面的不通过先别做后面的）

### A. 启动和目视（5 分钟）

用 `启动Qt桌面端.cmd` 启动。看：

1. 窗口、字体、图标、动效是否正常；菜单靠近屏幕边缘时位置是否正确（我只在离屏环境验证过，没看过真实窗口）。
2. 设置页能看到“学习旧切片”“字幕识别”“AI”三张卡片，布局不挤。
3. 封面页：点“全片”选七张，再依次点其中几张——大图应该换，**下面七张缩略图不变**；点“当前帧”才回到附近帧。
4. 封面页：抠人物后，人物周围没有光晕和重影。

### B. 学习旧切片（只读，安全）

先在命令行看看你的旧文件夹是怎么被认出来的（不写任何东西）：

```bash
python -m autoslice.desktop.archive inspect <你的旧切片根目录>
```

认得对再扫描：设置页“学习旧切片”添加文件夹后开始，或命令行 `scan`。扫完看 `report.md`，在“学到的建议”里确认要采用的固定纠错和术语。

带回来：`digest.json`（可以整份交给 GPT，没有视频、没有完整路径）和你的观感（认错的文件夹类型、建议里明显不对的条目）。**这条路径还没在你的真实旧数据上跑过**，是本轮最需要实测的一块。

### C. 字幕识别（最重要）

识别要在装了 torch 的 Python 里跑，Qt 虚拟环境里没有。下面用 `scripts\asr_tool.cmd`（先设 `AUTOSLICE_ASR_PYTHON` 指向那个 Python，不设就用 PATH 里的）：

```bash
scripts\asr_tool.cmd setup
```

按提示装 PyTorch（CUDA 版）和 `qwen-asr`（官方建议 Python 3.12），然后：

```bash
scripts\asr_tool.cmd doctor
```

```bash
scripts\asr_tool.cmd doctor --probe
```

`--probe` 会真的加载模型试跑 3 秒静音，第一次会下载模型（识别模型约 4GB（模型卡写的是 2B 参数、BF16）、对齐模型 0.6B 约 1~2GB，合计大约 5~6GB，以下载时显示的为准；下不动按 `setup` 里的 ModelScope 办法）。它验证三件事：模型能加载、`qwen-asr` 的热词参数是否被接受、显存占多少。

通过后拿你自己的旧字幕选引擎：

```bash
scripts\asr_tool.cmd bench --root <你的旧切片根目录> --engines qwen3-asr,funasr --out bench.md
```

最后在界面里实测：设置页“字幕识别”里把“识别用的 Python”填成那个 torch 环境的 `python.exe`，保存，字幕页选一个**没有字幕**的视频，点“识别字幕”，看进度、取消、再继续、完成后是否自动载入。

带回来：`doctor --probe` 的完整输出、`bench.md`、识别一条真实视频的耗时和观感（错字、断句、时间轴是否对得上）。

### D. 同音检查

需要术语表里有词才有结果：先做完 B（确认一批学到的术语），再打开一条有“术语被写错同音字”的字幕，点 AI 面板里的闪电按钮。应该出现待确认建议，采纳后可以撤销。

### E. 打包（可选，最后做）

按 [PACKAGING.md](PACKAGING.md) 在主力机上运行 `packaging\build_windows.ps1`。**没在任何机器上构建过**，第一次大概率要小修；把完整输出带回来就行。

## 已知没验证的、风险

| 项 | 说明 |
|---|---|
| Qwen3 适配 | 没碰过真模型。热词参数是否被接受、时间戳返回形状都是宽容解析，以 `doctor --probe` 为准 |
| `qwen-asr` 在 Windows 的安装 | 官方文档没提 Windows；装不上就用 WSL/别的环境，设置里把“识别用的 Python”指过去 |
| 说话人过滤 | 旧识别的 CAM++ 只留主讲人，新路线没有；直播里常有别人说话的话，用 `bench` 看影响 |
| 同音检查的真阳性 | 仅在本机 2 份真实字幕（294 条）上验证过没有误报；效果取决于你学到的术语表 |
| 打包 | 只做了语法检查和源码模式 `--smoke` |
| 真实窗口 | DPI、字体 fallback（标题里的 emoji）、动效手感、菜单靠屏幕边缘的位置，都只在离屏环境看过 |

## 还在等你拍板的

- 旧 Tk 界面（`桌面端.py`、`autoslice.desktop.app`）是否删除。
