# Desktop vNext 产品契约

## 定位与范围

- AutoSlice Desktop vNext 是个人视频后处理工作台：接收剪映导出的视频和字幕，服务于上传 B 站之前的处理。
- 主流程只有两项高频工作：字幕校对与字幕压制、封面制作。用户可直接进入任一工作台，不依赖自动分析或自动切片。
- 默认投稿根目录为 `F:\Videos\投稿`；每个标题文件夹是一个项目。刷新扫描后自动出现在功能页项目列表，不要求手动“添加项目”。目录是项目事实来源，应用状态只补充草稿、任务等信息。
- 自动分析录播与自动切片旧能力冻结；可保留旧实现供参考和过渡，未来仅考虑作为高级/实验工具，不进入 vNext 主界面。
- 不建设发布准备流程，也不管理 B 站标题、简介和标签；沿用 B 站已有功能。

## 产品取舍

- 优先解决真实操作中的等待、重复定位、跨软件核对和重复编辑；新增功能应能明显缩短完成一条视频的时间。
- AI 只辅助用户判断和起稿；由用户主动触发，结果可核对、可编辑。不能为了自动化而增加操作或遮蔽原视频、字幕和画布。
