# AutoSlice Desktop vNext 产品定位与边界

## 一句话定位

**AutoSlice 是面向直播切片员的 AI 辅助速切工作台。**

它把已有的剪映成片、字幕校对、封面制作和压制步骤收拢到一套可恢复的桌面工作流中，让切片员更快完成重复性检查和包装，同时把最终判断留给人。

## 真实工作流

桌面端服务的真实顺序是：

```text
剪映完成视频
    → 字幕校对
    → AutoCover
    → 压制
    → 投稿
```

- **剪映完成视频**：视频剪辑、节奏、镜头和最终内容仍由剪辑员在剪映中完成。
- **字幕校对**：在 AutoSlice 中打开对应项目，播放视频，校对字幕正文和时间边界，按既有语义保存校对字幕。
- **AutoCover**：从当前视频和播放头继承素材，选帧、整理确定性基础文案、调整封面对象并导出 4:3 / 16:9。
- **压制**：使用已保存的校对字幕和既有压制契约生成成片，任务在后台运行并显示项目来源。
- **投稿**：导出结果交给切片员做最后检查和投稿；AutoSlice 不自动发布或跨平台分发。

字幕和封面共享项目扫描结果，但不共享彼此的编辑状态。切换页面时，正在运行的后台任务继续属于原项目，迟到结果不能覆盖当前项目。

## 做什么

AutoSlice Desktop vNext 负责四类工作：

1. **字幕**：视频播放、字幕校对、时间轴调整、AI 建议的人工采纳/跳过、草稿恢复、显式保存和后台压制。
2. **封面**：在当前视频上快速完成选帧、基础文案、双比例布局、素材调整、保存和导出。
3. **设置**：放置字体、默认样式、路径和设备等低频配置，不让日常工作流被参数表占据。
4. **工作状态**：显示当前项目、后台任务、保存状态和可恢复入口，避免用户因切页或重启丢失工作。

## 明确不做

产品边界已经收窄，以下内容不属于 AutoSlice Desktop 的目标：

- 不做剪辑，不做视频剪辑器、时间线剪辑、镜头拼接或剪映替代品。
- 不做复杂特效、动画、贝塞尔路径、复杂蒙版、通道、曲线、Liquify 或完整滤镜系统。
- 不做花式字幕编辑器；字幕语义、校对保存和既有压制契约保持稳定。
- 不做运营平台、账号体系、任务发布中心、自动投稿、跨平台分发或多人协作。
- 不做 Photoshop/Canva 替代品；AutoCover 只提供快速、可编辑、可回退的封面包装能力。
- 不做模板市场、素材交易、公开模板社区或需要长期维护的在线内容平台。
- 不在后台默认运行 AI、整片扫描、主体抠图或自动改写文案。

## 速切与精切的边界

AutoSlice 的核心价值是**速切辅助**：把扫描、取帧、字幕校对、基础包装和重复任务变快，并为不确定处提供可回退的建议。

精切判断仍由剪辑员完成，尤其是：

- 镜头是否应该保留、删除或重新安排；
- 语气、节奏和上下文是否构成完整片段；
- 封面最终是否准确表达视频内容；
- 字幕和封面是否适合投稿语境；
- AI 建议是否应该采纳。

产品不因“自动”二字而把猜测写入正式字幕、封面或投稿文件。无法可靠判断时，显示来源和候选，让用户选择。

## 主导航

桌面端的一级导航固定为三个入口：

### 字幕

字幕是高频主工作台。主界面围绕项目、播放器、轻量时间轴、字幕列表和按需展开的 AI 建议组织。选中字幕、播放所在字幕、hover 和 playhead 必须保持不同语义；文字编辑时快捷键归编辑框处理，退出编辑后恢复窗口级快捷键。

### 封面

封面是快速包装工作台。画布是中心，右侧只显示当前对象需要的上下文属性；素材、AI 和低频参数使用抽屉或“更多”入口，不把所有能力长期摊平。

### 设置

设置承载字体、默认样式、路径和设备状态等低频信息。日常字幕与封面不要求用户理解内部缓存、布局参数、模型 transport 或文件指纹。

## 产品原则

- **内容优先**：视频、字幕正文和封面画布是视觉中心，状态和参数服从当前任务。
- **人可接管**：自动建议必须可预览、可撤销、可跳过；手工改动不能被后台任务悄悄覆盖。
- **默认安静**：AI、全片扫描、复杂调整和高风险操作都由用户显式触发。
- **结果可恢复**：草稿、选帧、封面对象和后台状态按项目隔离，重启后可以继续。
- **快速但不猜**：确定性逻辑负责提取和压缩；事实不完整时回退原文或让用户选择。
- **一次只做一件事**：界面优先支持当前动作，低频能力在需要时出现。
