# Desktop vNext 当前事实

更新日期：2026-09-28；来源：Desktop-01 对当前 AutoSlice 仓库的静态代码审计。详细实现位置、输入输出和迁移判断见 [MIGRATION_MAP.md](MIGRATION_MAP.md)。

- 当前生产实现位于 `src/autoslice/` 和 `src/autoslice_cover/`；旧 Web 页面分别调用 Python 字幕工作流与 AutoCover 工作区/渲染器。
- 投稿根目录由配置或页面输入确定。本机配置的投稿目录已确认存在。字幕工作台递归扫描 `.flv/.mp4/.mkv/.mov/.avi`，优先配对同目录同名 SRT；缺字幕视频仍出现在队列中。
- SRT 解析、删除/合并/时间修改、校对 SRT 与编辑状态保存已有独立 Python 函数；源 SRT 不会被校对保存覆盖。
- AI 字幕检查按批处理并缓存建议，不直接写源字幕；建议包含 cue 序号、原文、修正文、理由、置信度和时间。采纳、忽略、手工保护与撤销状态主要保存在旧页面内存中。
- 字幕压制由 SRT 生成 ASS，经 FFmpeg 输出新 MP4；默认样式与导出参数集中定义，并要求精确字体。字幕页当前只提供指定时间的静帧预览，没有连续视频播放器或点击 cue 后播放的实现。
- AutoCover 可独立扫描切片目录、选帧、编辑文字与贴图、生成 16:9 和 4:3 封面。两比例的编辑状态各自保存；同步开关在旧页面复制布局。磁盘草稿保存恢复信息。
- 模型传输已有 OpenAI/Anthropic 兼容协议、显式配置、重试与错误处理；字幕和封面调用共用传输层。AutoSlice 后台任务使用 SQLite 注册表、线程、SSE 与协作取消，重启后遗留活动任务标记为 `interrupted`。
- 自动分析/自动切片与字幕工作台、AutoCover 是不同入口；字幕自动识别和参考标题经 `topic_engine` 服务入口，AutoCover 可以选择读取精调 manifest，但扫描及封面渲染不要求运行自动切片。

## Desktop-03 实现与验证

- 旧扫描器返回逐视频记录，而产品契约要求每个标题文件夹为一个项目；桌面服务只做分组适配。即使文件夹为空或缺少字幕，也显示项目及简短状态。根目录下散放的文件不构成项目。扫描是手动刷新，不使用文件监听。
- 已运行项目服务单元测试，覆盖默认路径/配置、旧配对和生成视频排除、项目与文件变化、空目录、缺失目录及不可读根目录；实际本机目录刷新得到 4 个项目。已实例化桌面窗口并切换三个一级页面，确认封面页复用同一个项目快照。旧启动器、字幕工作流及 AutoCover 工作区定向回归通过。GUI 布局仍需在用户实际桌面上目视检查。
