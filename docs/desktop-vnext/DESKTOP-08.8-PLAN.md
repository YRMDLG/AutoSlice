# Desktop-08.8 字幕工作台体验收口计划

## 核心定位
AutoSlice 不是 Subtitle Edit/Aegisub 的替代品，也不是字幕设计软件；它是 AI 辅助的视频字幕校对工作台。
原则：少操作、快确认、少打断。剪映的交互习惯优先，专业字幕软件只参考高价值能力。

## 已冻结事项
- 旧版字幕样式保持不动，继续复用现有字体、字号、颜色、描边、位置与 ASS/压制逻辑。
- 主界面不新增字幕模板、动画、KTV、逐字特效、复杂样式面板。
- 字幕预览默认开启，除非用户主动关闭。
- 播放器中的字幕预览必须尽量与最终压制效果一致。
- 用户在底部修改字幕文字时，上方预览必须立即同步，不能有明显等待感。
- 波形默认可见，默认高度必须足够阅读；不应要求用户每次手动拉开才能看懂。
- 时间轴/波形高度允许调整，并记忆用户上次设置。
- 点击字幕后 playhead 自动跳到字幕开头这一行为保留，不再作为问题处理。

## 时间轴交互冻结
- 空白位置单击：playhead 立即跳到点击时间并暂停。
- 只有抓住 playhead 本体后拖动，才进入连续 scrub；普通鼠标移动不能带着 playhead 走。
- 字幕块普通点击：只做选中/定位，不应直接进入移动。
- 字幕块按住后拖动：移动字幕块。
- 字幕块左/右边缘按住拖动：调整 start/end。
- 只有靠近左右边缘时才显示 resize 光标/高亮；字幕块中部不应显示边缘调整光标。
- 鼠标释放后拖动状态必须立即结束，禁止出现“字幕块粘在鼠标上”的状态残留。
## 字幕编辑冻结
- 禁止双击字幕进入编辑；这一行为永远不要加入。
- 单击字幕正文即可进入编辑，caret 落在实际点击字符位置。
- 编辑时视觉应像“文字本身可编辑”，不要出现黑色输入框、厚边框、额外编辑模式或布局跳动。
- 编辑状态不能重复绘制原文本与 editor 文本。
- 连续输入时 caret 不能跳回开头，IME 中文输入必须稳定。
- 修改文字后播放器字幕预览同步更新。

## AI 检查冻结
- AI 的职责是“发现问题 + 带用户到问题位置”，不是复杂修复审核系统。
- 点击 AI 问题：跳到对应字幕、选中、播放头定位、暂停，用户随后自行听/改/采纳/跳过。
- 不做 AI 修复成片预览、不做多余二次确认流程。
- AI 侧栏需要提高空间利用率：当前建议清楚展示，其余待确认项做紧凑导航列表，避免大片空白。

## 快捷键冻结
- F1：试听当前字幕，从字幕 start 播放到 end，然后停止。
- F2：试听字幕开头边界，从 start 前 0.5 秒播放到 start，立即停止；用于检查开头是否漏字/切晚。
- F3：试听字幕结尾边界，从 end 开始播放约 0.5 秒，停止；用于检查是否切早/漏尾。
- F4：当前字幕从 start 到 end 完整播放一次，停止；按一次只播放一次，不是循环开关。
- Space：播放/暂停。
- Q：左裁到 playhead；W：右裁到 playhead。
- Ctrl+B：拆分字幕。
- Delete：删除所选字幕。
- Ctrl+Z / Ctrl+Y：撤销 / 重做。
- 后续可在设置页加入快捷键重映射、冲突检测、恢复默认；本轮不做。
## 当前阶段顺序
### Desktop-08.8.2 — 字幕预览可信化
- 优先修字幕预览渲染位置/尺度/样式问题。
- 预览与正式压制必须共用同一套 ASS 生成与字幕样式来源。
- 重点核对 PlayResX / PlayResY / Alignment / Margin / FontSize / Outline / Shadow。
- 保持已修复的稳定 mpv 链路：首次 sub-add，后续原子替换同一路径 preview.ass + sub-reload；关闭预览只隐藏。
- 真实验收：修改文字立即反映在视频；长字幕换行合理；预览与真实压制截图位置和样式一致。
- 本阶段不改 playhead 自动跳到被点击字幕开头的既有行为。

### Desktop-08.8.3 — 字幕编辑体验
- 修复重复文字显示、caret 跳回开头、IME 输入不稳定等问题。
- 单击正文即原位编辑；点击哪里 caret 到哪里。
- 不使用黑色输入框感、双击编辑、独立编辑模式。
- 连续输入/删除/中文输入法下保持 caret 和编辑器生命周期稳定。

### Desktop-08.8.4 — 时间轴剪映化
- 修复字幕块拖动状态机和 mouse release 清理，禁止粘鼠标。
- 字幕块中部与左右边缘 hit-zone 明确分离。
- 只有左右边缘 hover 时显示 resize cursor 与边缘高亮；中部按住拖动才移动。
- 保留磁吸、波形、多选、Q/W、Ctrl+B 等已实现能力，不扩展新功能。

### 最后 — AI 侧栏布局收口
- 不增加 AI 能力，只重新利用空间和问题导航。
- 当前问题突出，其余问题紧凑列出并可点击跳转。

## 明确暂不做
- 校对/编辑/压制模式切换。
- 字幕时间帧级/毫秒级微调快捷键。
- 复杂字幕模板、动画、KTV、卡拉 OK、视频多轨、频谱、关键帧。
- AI 复杂自动修复预览。
- 视频画面内直接拖动字幕样式。
- Desktop-09 封面功能，直到以上字幕体验收口并完成实机验收。

## 验收原则
每个阶段必须真实 Qt/mpv 实机验收，不以“单元测试通过”代替手感验收。重点看：输入是否自然、播放器预览是否可信、鼠标是否跟手、状态是否清楚、是否有程序抢控制权。
